화면 속 무언가에서 텍스트를 뽑는 가장 빠른 방법은 파일을 아예 거치지 않는 것입니다. 스크린샷을 클립보드로 캡처하고, 이 탭으로 와서 붙여 넣은 뒤 결과를 복사하세요. 업로드 버튼을 찾을 필요도, 다운로드 폴더를 뒤질 필요도 없습니다.

## 클립보드로 복사되는 스크린샷 단축키

대부분의 시스템은 기본적으로 스크린샷을 파일로 저장합니다. 아래 단축키를 쓰면 캡처가 클립보드로 들어가 바로 붙여 넣을 수 있습니다.

- **Windows:** Win+Shift+S를 눌러 캡처 도구 막대를 열고 원하는 영역을 드래그하세요. 캡처한 이미지가 클립보드에 복사됩니다.
- **Mac:** ⌘+Shift+Ctrl+4를 누르고 드래그해 영역을 선택하세요. 평소 단축키에 Ctrl을 더하면 스크린샷이 데스크탑 대신 클립보드로 갑니다. ⌘+Shift+Ctrl+3은 화면 전체를 복사합니다.
- **Chromebook:** Ctrl+Shift+창 표시 키를 눌러 화면 캡처를 열고 영역을 선택하세요. 붙여 넣어도 들어오지 않으면 저장된 스크린샷 파일을 페이지에 끌어다 놓으세요.
- **iPhone과 Android:** 스크린샷을 클립보드로 바로 보내는 단축키가 없습니다. 스크린샷은 사진 앱이나 갤러리에 저장되며, 거기서 추가하면 됩니다.

스크린샷이 클립보드에 들어갔다면 Ctrl+V(Mac은 ⌘V)를 누르세요. 페이지의 어느 위치에 있든 상관없습니다.

## 사람들이 가장 많이 캡처하는 것

- **채팅과 메시지.** 대화를 인용하거나, 약속 내용을 저장하거나, 단체 채팅방에서 주소를 뽑아낼 때 씁니다. 이름과 시간은 별도의 줄로 나오므로 쉽게 지울 수 있습니다. 긴 대화라면 스크린샷을 여러 장 찍어 차례로 붙여 넣으세요.
- **오류 메시지와 대화 상자.** 정확한 문구를 복사해 검색하거나 버그 보고서에 넣을 수 있습니다. 스택 트레이스와 코드는 [코드 스크린샷 페이지](/ko/code-screenshot-to-text)에서 코드 모드가 들여쓰기를 어떻게 유지하는지 확인하세요.
- **텍스트 선택을 막아 둔 기사와 페이지.** 화면에 보인다면 스크린샷을 찍어 여기에 붙여 넣으면 됩니다.
- **화상 회의나 녹화 강의의 슬라이드.** 일시 정지하고 슬라이드를 캡처해 붙여 넣으세요. 문서 모드는 제목과 글머리 기호 목록을 유지하므로 필기할 때 편리합니다.
- **보고서와 대시보드의 표.** 표 모드는 스프레드시트에 붙여 넣을 수 있는 표로 바꿔 줍니다. [이미지 엑셀 변환](/ko/image-to-excel)을 참고하세요.

## 잘 읽히는 스크린샷 찍기

화면 전체보다는 필요한 영역만 캡처하세요. 꼭 맞게 선택하면 메뉴, 아이콘, 사이드바가 빠지는데, 이런 요소가 있으면 OCR 엔진이 텍스트로 읽으려고 합니다.

글씨가 작다면 캡처하기 전에 확대하세요. 자동 보정이 작은 글씨를 키우긴 하지만, 글자당 픽셀이 많을수록 언제나 유리합니다. 다크 모드는 따로 신경 쓸 필요가 없습니다. 어두운 배경 위의 밝은 글자는 자동으로 반전됩니다.

모니터를 휴대폰으로 찍지 말고 실제 스크린샷을 쓰세요. 화면을 찍은 사진에는 빛 반사, 물결무늬, 흔들림이 생기지만 스크린샷에는 그런 문제가 없습니다.

인증 코드, 주문 번호, 일련번호처럼 주변에 단어가 없는 문자열은 모든 문자를 원본과 비교하세요. 줄을 클릭하면 이미지에서 그 위치가 강조되므로 빠르게 확인할 수 있습니다.

## 기본 제공 도구, 그리고 이 페이지가 유용한 경우

사용 중인 기기에 이미 스크린샷에서 텍스트를 복사하는 기능이 있을 수 있습니다. Windows 캡처 도구의 텍스트 작업, Mac과 iPhone의 라이브 텍스트, Android의 Google 렌즈, Windows용 PowerToys 텍스트 추출기가 그렇습니다. 한 줄만 가져올 때는 이런 도구가 가장 빠른 경우가 많습니다.

Image to Text App은 그 이상이 필요할 때 유용합니다. 엔진이 확신하지 못한 단어를 복사 전에 검토하거나, 여러 스크린샷을 올바른 순서로 하나의 문서로 합치거나, 표를 표 형태 그대로 유지하거나, 결과를 Word, Markdown, CSV, 검색 가능한 PDF로 다운로드하고 싶을 때입니다.

## 스크린샷에는 개인 정보가 많습니다

스크린샷에는 이름, 메시지, 계정 정보처럼 공개하고 싶지 않은 내용이 담기기 쉽습니다. Image to Text App은 이를 내 기기의 브라우저 안에서 읽으므로 이미지가 서버로 전송되지 않습니다. 기록은 직접 켜기 전까지 꺼져 있고, 켜더라도 브라우저 안에만 저장됩니다. "링크 복사"로 결과를 공유하면 텍스트는 업로드되지 않고 링크 자체에 담깁니다. 자세한 내용은 [온라인 OCR은 안전한가요?](/ko/guides/is-online-ocr-private)에서 확인하세요.

시스템별로 더 자세한 단계별 설명은 [스크린샷에서 텍스트를 추출하는 방법](/ko/guides/how-to-extract-text-from-a-screenshot) 가이드를 참고하세요.
