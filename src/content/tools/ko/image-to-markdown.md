## 일반 텍스트 대신 Markdown을 쓰는 이유

일반 텍스트는 구조를 잃습니다. 제목은 다른 줄과 똑같아 보이고, 목록은 흩어진 문장이 되며, 표는 순서가 뒤섞인 단어 더미가 됩니다. Markdown은 평범한 문자로 이 구조를 지키기 때문에 거의 어디에 붙여 넣어도 구조가 유지됩니다.

같은 결과를 Markdown을 저장하는 노트 앱, 문서 사이트, 위키, README 파일, AI 어시스턴트와의 채팅에서 그대로 쓸 수 있습니다. 원본 텍스트 상태로도 읽기 쉽고, 손으로 편집하기 쉬우며, 버전 관리에서 변경 내용이 분명하게 보입니다.

## 페이지의 각 부분이 작성되는 방식

콘텐츠마다 고유한 Markdown 형식이 있습니다.

| 이미지에 있는 것 | Markdown에서는 |
| --- | --- |
| 제목 | `#` 하나 이상으로 시작하는 줄 |
| 글머리 기호 | `- `로 시작하는 줄 |
| 번호 목록 | `1.`, `2.` 등으로 시작하는 줄 |
| 표 모드로 읽은 표 | 열 사이에 파이프가 있는 Markdown 표 |
| 코드 모드로 읽은 코드 | 펜스 코드 블록 |

짧은 체크리스트의 스크린샷을 문서 모드로 읽으면 이런 결과가 나올 수 있습니다.

```markdown
# Release checklist

Run these before tagging a new version.

- Freeze the main branch
- Update the changelog

1. Build the package
2. Run the full test suite
```

문단 안에서 줄바꿈된 줄은 합쳐지고, 줄 끝에서 하이픈으로 나뉜 단어는 다시 이어지므로, 문단이 여러 개의 끊긴 줄이 아니라 Markdown 한 줄이 됩니다.

## 글, 표, 코드가 섞인 페이지

각 이미지는 한 번에 한 가지 모드로 읽으며, 모드는 이미지마다 따로 고릅니다. 문단 옆에 표가 있는 스크린샷이나 중간에 코드 예제가 있는 튜토리얼 페이지라면 이 점이 중요합니다. 문서 모드는 일반 글에 맞춰져 있어서, 표를 문서 모드로 읽으면 보통 표가 아니라 텍스트 줄로 나옵니다.

해결 방법은 페이지를 나누는 것입니다. 글 부분과 표나 코드 부분을 따로 스크린샷으로 찍고, 각각을 알맞은 모드로 설정한 뒤 끌어서 순서를 맞추세요. 그러면 전체 문서 보기에서 모든 페이지를 Markdown 파일 하나로 합치거나, 페이지마다 파일이 하나씩 담긴 ZIP으로 받을 수 있습니다.

표가 많은 이미지라면 [이미지에서 표를 추출하는 방법](/ko/guides/how-to-extract-tables-from-images)에서 행과 열을 제대로 얻는 방법을 다룹니다. 코드 예제라면 [코드 스크린샷 텍스트 변환](/ko/code-screenshot-to-text)에서 괄호나 비슷하게 생긴 문자처럼 다시 확인해야 할 부분을 설명합니다.

## AI 프롬프트에 Markdown 활용하기

AI 어시스턴트와의 채팅에 이미지 대신 텍스트를 붙여 넣으면 무엇을 보여 줄지 직접 통제할 수 있습니다. 먼저 텍스트를 읽어 보고, 잘못 읽힌 단어를 고치고, 개인적이거나 관련 없는 내용을 빼고, 제목, 목록, 표를 분명하게 표시된 상태로 둘 수 있습니다.

Markdown으로 붙여 넣은 표는 행과 열이 텍스트로 유지되므로 "3월 열과 4월 열을 비교해 줘"처럼 질문에서 바로 가리킬 수 있습니다. 번호 목록은 번호가 유지되므로 "3단계를 다시 써 줘"가 나와 어시스턴트에게 똑같은 의미가 됩니다.

## 붙여 넣기 전에 결과 다듬기

몇 가지만 빠르게 확인하면 Markdown이 더 깔끔해집니다.

- **제목 수준.** 페이지 제목과 섹션 제목이 원하는 수준으로 나왔는지 확인하세요. `#`를 더하거나 빼는 것은 금방입니다.
- **여러 스크린샷에 걸친 번호 목록.** 한 스크린샷에서 다음 스크린샷으로 이어지는 목록은 다시 1부터 시작할 수 있으니, 페이지를 합친 뒤 번호를 확인하세요.
- **유지하고 싶은 줄바꿈.** 시, 주소, 노래 가사라면 줄바꿈된 줄 합치기를 꺼서 모든 줄을 원래대로 두세요.
- **반복되는 오류.** 한 단어가 처음부터 끝까지 같은 식으로 잘못 읽혔다면 찾아 바꾸기로 한 번에 고치세요.

워드 프로세서에서 마무리하고 싶다면 [이미지 워드 변환](/ko/image-to-word)으로 같은 제목과 목록이 담긴 .docx를 받으세요.
